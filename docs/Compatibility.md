# WIMC 兼容性与适配设计

> 说明：本文档记录目标系统范围、任务栏与多屏 DPI 适配方案、公开 API 边界及降级回退策略。

## 1. 背景参考与问题记录（待复现参考）
维护者在使用传统 `explorer.exe` 注入式工具时观察到：Windows 11 25H2 及 26H2 初始版本表现正常，但在 26H2 后续更新（如 Build 26300.9550+）中出现无法嵌入任务栏、锁死在最左侧、在托盘区下沉裁切等故障。
- **应对原则**：在无官方内部符号证据前，不对系统内部未公开改动做主观定性；WIMC 采用独立顶层窗口外部对齐方案，完全隔离 `explorer.exe` 进程空间。

## 2. Windows 11 版本测试计划
- **23H2 (22631.x)**：基础兼容，验证 GSMTC 与 DWM 圆角表现。
- **24H2 (26100.x) / 25H2 (26200.x)**：重点支持，验证非激活窗口焦点保持、多屏 DPI 与全屏避让。
- **26H2 (26300.9550+)**：核心目标环境，重点验证独立悬浮窗在最新任务栏下是否出现偏移、沉底或遮挡。

## 3. 任务栏位置与状态策略
- **模式 A：屏幕顶部居中（默认推荐）**：定位于显示器顶部中央（距顶端 8~12 DIP），彻底避开底部任务栏与托盘冲突。
- **模式 B：任务栏外部伴随**：
  - 底部/顶部/侧边任务栏：定位于任务栏外边缘内侧安全距离，不侵入任务栏内部区域。
  - 自动隐藏（Auto-Hide）：通过 `SHAppBarMessage(ABM_GETSTATE)` 检测 `ABS_AUTOHIDE`，开启自动隐藏时固定于屏幕安全边距内，避免随任务栏抽动闪烁。

## 4. 任务栏坐标与工作区探测
结合两个公开 Win32 API 交叉校验：
1. `SHAppBarMessage(ABM_GETTASKBARPOS)`：读取任务栏物理像素矩形 `rc` 与停靠边缘 `uEdge`。
2. `GetMonitorInfo`：读取显示器完整矩形 `rcMonitor` 与可用工作区 `rcWork`，以 `rcWork` 边界作为防越界兜底。

## 5. 单屏、多屏与 DPI 缩放适配
- **DPI 感知**：声明 `PerMonitorV2`，按 `PhysicalPixels = LogicalDip * (MonitorDpi / 96.0)` 换算坐标。
- **动态响应**：监听 `WM_DPICHANGED` 实时重算窗口尺寸；监听 `WM_DISPLAYCHANGE` 处理多显示器拔插，目标屏幕断开时自动迁回主显示器（Primary Monitor），防止窗口滞留屏幕外。

## 6. 公开 API 边界与降级回退策略
- **定位降级**：若 `SHAppBarMessage` 失败或返回矩形宽高异常，自动回退至主显示器顶部居中安全坐标。
- **元数据降级**：当播放器未提供 `Thumbnail` 流时显示内置默认图标；歌手为空时隐藏副标题。
- **材质降级**：远程桌面、省电模式或不支持 Acrylic/Mica 时，自动回退为带圆角的半透明纯色背景。

## 7. 系统更新后回归验证清单
每次 Windows 更新后执行 5 项快速验证：
1. 记事本连续打字时点击浮岛按钮 5 次，确认不丢焦点。
2. 确认窗口位于预设锚点，无靠左锁死或下沉截断。
3. 切换 125% / 150% 缩放，确认布局与字体清晰。
4. 交替播放音乐软件与浏览器视频，确认会话跟随与控制正常。
5. 静置 3 分钟观察内存是否稳定在目标区间。
